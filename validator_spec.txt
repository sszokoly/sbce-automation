
platform_type - String, either "KVM" or "ESXI", it cannot be empty
platform_address - String, must be a valid IPv4 address or if it is an FQDN it must be resolvable to an IPv4 address, it cannot be empty
platform_username - String, it cannot be empty
platform_password - String, it cannot be empty
datastore - String, it cannot be empty
ovf - String, it cannot be empty
vmname - String, it cannot be empty
ipmode - String, either "DUAL_STACK" or "IPV4", it cannot be empty
hostname - String up to 20 characters, it cannot be empty
apptype - String, either "EMS+SBCE" or "EMS" or "SBCE", it cannot be empty
appname - String up to 20 characters, it cannot be empty and if "apptype" is "SBCE" cannot be the same as the "vmname"
nwpass - String, if empty defaults to "avaya"
ems_inst_type - String, either "primary" or "secondary", if "apptype" is not "EMS" set it to empty string 
ip0 - String, must be a valid IPv4 address, can be empty if "ipv6address0" is not empty
netmask0 - String, must be a valid IPv4 subnet mask (for example "255.255.255.0" or "/24") , can be empty if "ipv6prefix0" is not empty
gateway = String, must be a valid IPv4 address, can be empty if "ipv6gateway" is not empty
ipv6address0 - String, must be a valid IPv6 address, can be empty if "ip0" is not empty
ipv6prefix0 - String, must be a valid IPv6 prefix, can be empty if "netmask0" is not empty
ipv6gateway - String, must be a valid IPv6 address, can be empty if "gateway" is not empty
domain_suffix - String, must be a valid domain suffix (for example "lab.local", that is a string that cannot start or end with "." but must have at least one "." in it), not cannot be empty
first_last_name - String, concatenation of "hostname" and "domain_suffix" with a "." in between, for example <hostname>.<domain_suffix>
organizational_unit - String, can only be empty if "apptype" is "SBCE"
organization - String, can only be empty if "apptype" is "SBCE"
locality - String, can only be empty if "apptype" is "SBCE"
state_province - String, can only be empty if "apptype" is "SBCE"
country - String, can only be empty if "apptype" is "SBCE"
timezone - String, a valid IANA time zone, use python 'zoneinfo'
ntpservers - String, mjust be either a valid IPv4 address or FQDN, or a list of valid IPv4 addresses or FQDNs separated by "," - for example "10.1.1.1" or "10.1.1.1,10.1.1.1" or "pool.ca.ntp.org", can be empty
ntpipv6 - String, a valid IPv6 address, can be empty
dns - String, must be a valid IPv4 address, cannot be empty
emsip - String, must be a valid IPv4 address, cannot be empty if ("apptype" is "SBCE" and "emsip_v6" is also empty) or ("ems_inst_type" is "secondary" and "emsip_v6" is also empty)
emsip_v6 - String, must be a valid IPv6 address, cannot be empty if ("apptype" is "SBCE" and "emsip" is also empty) or ("ems_inst_type" is "secondary" and "emsip" is also empty)
rootpass - String of at least 8 characters, containing at least 1 uppercase letter, at least 1 lowercase letter, at least one number and at least special character from the following: hyphen (-), underscore (_), at sign (@), asterisk (*), or exclamation point (!). It cannot be the number sign (#), dollar sign ($), or ampersand (&).
ipcspass - String of at least 8 characters, containing at least 1 uppercase letter, at least 1 lowercase letter, at least one number and at least special character from the following: hyphen (-), underscore (_), at sign (@), asterisk (*), or exclamation point (!). It cannot be the number sign (#), dollar sign ($), or ampersand (&).
grubpass - String of at least 8 characters, containing at least 1 uppercase letter, at least 1 lowercase letter, at least one number and at least special character from the following: hyphen (-), underscore (_), at sign (@), asterisk (*), or exclamation point (!). It cannot be the number sign (#), dollar sign ($), or ampersand (&).
ucsecpass - String of at least 8 characters, containing at least 1 uppercase letter, at least 1 lowercase letter, at least one number and at least special character from the following: hyphen (-), underscore (_), at sign (@), asterisk (*), or exclamation point (!). It cannot be the number sign (#), dollar sign ($), or ampersand (&).
M1 - String, cannot be empty
M2 - String, cannot be empty if ("apptype" is "EMS") or ("apptype" is "SBCE" and "ha_peer_node" is not empty)
A1 - String, can only be empty if "apptype" is "EMS"
A2 - String, can only be empty if "apptype" is "EMS"
B1 - String, can only be empty if "apptype" is "EMS"
B2 - String, can only be empty if "apptype" is "EMS"
ha_peer_node - String, can be empty if "ha_peer_ip" is also empty, it cannot be empty if "ha_peer_ip" is not empty
ha_peer_ip - String, can be empty if "ha_peer_node" is also empty, it cannot be empty if "ha_peer_node" is not empty
sig_iface - String of either "A1" or "A2" or "B1" or "B2", can only be empty if "apptype" is "EMS"
sig_name - String of up to 20 characters, can only be empty if "apptype" is "EMS"
sig_mask - String, must be a valid IPv4 subnet mask or a valid IPv6 network prefix, can only be empty if "apptype" is "EMS"
sig_gw - String, must be a valid IPv4 address or a valid IPv6 address, can only be empty if "apptype" is "EMS"
sig_ip - String, must be a valid IPv4 address or a valid IPv6 address, can only be empty if "apptype" is "EMS" and cannot be the same as "ip0"


Other restrictions across the sheets:
- each "ip0" must be unique
- each "hostname" must be unique
- each "vmname" must be unique
- each "appname" must be unique unless "ha_peer_node" is not empty, the presence of a none empty "ha_peer_node" and none empty "ha_peer_ip" indicates the SBCE sheet is in a HA pair with another SBCE sheet in which case both sheets must have the same "appname"
- each "sig_ip" must be unique unless "ha_peer_node" is not empty, the presence of a none empty "ha_peer_node" and none empty "ha_peer_ip" indicates the SBCE sheet is in a HA pair with another SBCE sheet in which case both sheets must have the same "sig_ip"
- one SBCE sheet can only be paired with another SBCE sheet
